Mocha → Latte

Colours map by name, as the Catppuccin style guide asks, using the official palette. Three elements keep their role instead of their name; icons/make_variants.py lists them.

NameMochaLatteUsed for
ExceptionBy nameInsteadWhy
#tile gradient Surface0 → Base → Mantle is light-to-dark in Mocha but dark-light-dark in Latte. Base → Mantle → Crust keeps the light in the top left.
#fold-shade Base Text A translucent shadow must darken; Latte's Base would lighten it.
#eye (icon and glyph) Crust Text The darkest ink on the pika. Latte's Crust is pale grey.
